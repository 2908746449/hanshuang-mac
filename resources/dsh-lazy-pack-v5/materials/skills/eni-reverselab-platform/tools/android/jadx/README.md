# JADX

DEX 到 Java 反编译器，支持 APK/DEX/AAR 等格式。

## 下载

- GitHub Releases：https://github.com/skylot/jadx/releases
- 下载最新 `jadx-gui-*.zip`（包含 GUI 和命令行版本）
- 解压到本目录

## 使用

```bash
bin/jadx -d output_dir target.apk      # 命令行反编译
bin/jadx-gui target.apk                # GUI 打开
```
