# Mobile Frida Tools

Frida 移动端辅助脚本和工具。

## 依赖

- Frida：https://frida.re/docs/installation/
- Frida Server（Android）：https://github.com/frida/frida/releases

## 安装

```bash
pip install frida-tools
```

将适用于目标设备架构的 `frida-server` 推送到设备。
