# Cutter

基于 Rizin 的图形化反汇编/逆向工程框架。

## 下载

- GitHub Releases：https://github.com/rizinorg/cutter/releases
- 下载 Windows 版本 `Cutter-*-Windows-x86_64.zip`
- 解压到本目录

## 使用

```bash
Cutter.exe <binary>
```
