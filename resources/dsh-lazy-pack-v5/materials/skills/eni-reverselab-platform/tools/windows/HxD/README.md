# HxD

Windows 十六进制编辑器。

## 下载

- 官网：https://mh-nexus.de/en/hxd/
- 下载安装程序，安装后将 `HxD.exe` 路径加入此目录的快捷方式
- 或下载 portable 版本直接放入本目录

## 使用

```bash
HxD.exe <file>
```
